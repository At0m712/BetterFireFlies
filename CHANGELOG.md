# 📋 Changelog - Better FireFlies

## [1.0.2]

### 🐛 Fixes & Improvements
- **Dynamic Light**: Preserved glowing dynamic light emission while securing updates to client-side only (prevents ghost light blocks on servers).
- **Client Commands**: Added localized messages for `/fireflylight` and `/fireflyparticles` (`en_us`, `fr_fr`).
- **Bottle Capture**: Added cooldown on glass bottle usage to prevent packet spam and item duplication.
- **Compatibility**: Excluded conflicting data-generation artifacts and improved version compatibility.
